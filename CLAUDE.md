# CLAUDE.md — Spain Energy Grid Risk Index

## Overview

Daily risk forecasting for the Spanish electrical grid (REE). A quantile LightGBM model predicts the 90th percentile of a PCA-derived risk index, prioritizing safety: missing a blackout (FN) costs 10x more than a false alarm (FP).

## Architecture

### Data Pipeline (Phase 1)

4 data streams -> `api_client.py` (paginated, retry) -> `extractors.py` -> `cleaning.py` (align, impute, calendar, HDD/CDD) -> `merged_daily_data.parquet`

- **Streams:** REE demand (hourly, resampled to daily mean), REE generation (daily), REE spot price (hourly, resampled), Open-Meteo weather (daily)
- **Granularity:** Daily
- **Coverage:** ~5 years (2021-present), ~1,898 rows, <0.1% missing
- **Timezone:** Date index, Europe/Madrid for calendar features

### Target & Features (Phase 2)

Three core risk factors (computed from actuals):

- `flexibility_share` = (combined_cycle + hydro) / total_generation
- `demand_forecast_error` = actual_demand - forecast_demand
- `net_load` = actual_demand - (wind + solar_pv)

**Risk Index:** StandardScaler -> PCA(3) -> PC1 -> MinMaxScaler -> [0, 1]

- Fitted on train only; thresholds at p20/p40/p60/p80 -> 5 categories
- Categories: Low, Stable, Elevated, Severe, Extreme

**15 Features (X):**

1. `forecast_demand_mw` — REE day-ahead demand forecast
2. `temperature_2m_max`, `temperature_2m_min` — Open-Meteo weather
3. `wind_speed_10m_max`, `shortwave_radiation_sum`, `precipitation_sum` — weather
4. `hdd`, `cdd` — heating/cooling degree days
5. `day_of_week`, `month`, `is_weekend`, `is_holiday` — calendar (Europe/Madrid)
6. `spot_price_eur_mwh` — REE spot price
7. `risk_index_lag_1d`, `risk_index_lag_7d` — temporal lags

**Chronological split:** train (->2023-12, 1,088 rows), val (2024-01->2024-06, 182 rows), test (2024-07->present, 620 rows)

### Model (Phase 3)

**Key decision: Quantile regression (a=0.90)** — the model predicts the 90th percentile of risk, making it systematically pessimistic. Standard RMSE is demoted; business metrics drive evaluation.

**Training pipeline:**

1. Persistence baseline (1-day lag)
2. Ridge baseline
3. Optuna hyperparameter search (30 trials, minimizes quantile loss on val)
4. Final LightGBM with best params + early stopping (patience=50)

**3 Business Metrics:**

- **A. Cost Matrix Penalty:** FN(Extreme)=10pts, FP(Extreme)=1pt — total penalty
- **B. F3 Score (Extreme class):** recall weighted 9x over precision (beta=3)
- **C. RMSE Skill Score:** % improvement over persistence baseline

**Latest results (test set, full data):**

- Cost reduction: 56.2% vs persistence
- F3 = 0.831 (strong Extreme-class recall)
- RMSE Skill Score: -32.9% (negative by design for quantile regression)

### Serving (Phase 4-7)

**FastAPI app (`app.py`):** Accepts a `target_date`, fetches live data from REE + Open-Meteo, computes features, predicts risk index with category.

**Docker:** `python:3.12-slim` + `libgomp1`, model baked in at build time, port 9696.

**CI/CD:** GitHub Actions — `train.yml` (reusable, sample data) -> `ci-cd.yml` (train -> lint -> Docker build -> test -> GHCR push).

**Deployment:** Render.com pulling from `ghcr.io`.

## Key Conventions

- **Pure logic in `src/`** — no file I/O in module functions; scripts handle I/O
- **PYTHONPATH=src** — required when running scripts (`PYTHONPATH=src uv run python scripts/...`)
- **joblib for serialization** — RiskIndexFit dataclass requires `grid_risk` on the import path
- **uv** as package manager — `pyproject.toml` at project root
- **Port 9696** — for both local dev and Docker

## Running

```bash
# Full training pipeline (local, full data, 30 Optuna trials)
PYTHONPATH=src uv run python scripts/train_model.py --n-trials 30

# CI training (sample data, skip tuning)
PYTHONPATH=src uv run python train.py --skip-tuning

# Start API locally
PYTHONPATH=src uv run python app.py

# Docker build + run
docker build -t spain-grid-risk:latest .
docker run -d -p 9696:9696 spain-grid-risk:latest

# Run tests (requires running server on port 9696)
PYTHONPATH=src uv run pytest test_api.py -v
```
